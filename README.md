
# 📊 Sales Performance Analysis Dashboard | Tableau

## 📌 Project Overview

This project focuses on analysing retail sales data to understand business performance, identify sales trends, evaluate profitability and examine regional performance.

An interactive Sales Performance Dashboard was developed using Tableau Public to transform raw sales data into meaningful visual insights and support data-driven business decisions.

The project covers key performance indicators (KPIs), monthly sales trends, category-wise performance, sub-category profitability and regional sales analysis.

## Project Objectives

- Analyse overall sales and profit performance.
- Identify monthly sales trends and patterns.
- Compare sales performance across different product categories.
- Evaluate profitability across product sub-categories.
- Analyse geographical sales distribution across states and regions.
- Present key business metrics through an interactive dashboard.

## Tools & Technologies Used

- **Tableau Public:** Data visualization and interactive dashboard development.
- **Microsoft Excel:** Dataset inspection and preliminary data handling.
- **CSV:** Data storage and input format.
- **GitHub:** Project documentation and version control.

## Dataset Description

The project uses a synthetic retail sales dataset containing 650 records.

The dataset includes the following attributes:

| Column | Description |
|---|---|
| Order ID | Unique order identification |
| Order Date | Date of purchase |
| Customer ID | Unique customer identification |
| Customer Segment | Customer classification |
| Region | Geographical sales region |
| State | State where the order was placed |
| City | City of the customer |
| Category | Main product category |
| Sub-Category | Specific product classification |
| Sales | Revenue generated from sales |
| Quantity | Number of products sold |
| Discount | Discount offered |
| Profit | Profit generated from the order |

## Key Performance Indicators (KPIs)

The dashboard includes four major KPIs:

1. **Total Sales:** Measures the overall revenue generated.
2. **Total Profit:** Measures the total profit earned.
3. **Profit Margin:** Evaluates profitability as a percentage of total sales.
4. **Average Order Value (AOV):** Measures the average revenue generated per order.

### Calculated Fields

The following calculated fields were created in Tableau:

**1. Profit Margin**
SUM([Profit]) / SUM([Sales])

**2. Average Order Value**
SUM([Sales]) / COUNTD([Order ID])

**3. Total Sales**
SUM([Sales])

**4. Total Profit**
SUM([Profit])

## 📊 Analysis & Visualizations
The dashboard consists of the following visualizations:

### 1. Monthly Sales Trend Analysis
Analyses monthly sales performance to identify trends, fluctuations and changes in revenue over time.

### 2. Category Performance Analysis
Compares sales performance across different product categories to understand which categories contribute most to overall revenue.

### 3. Sub-Category Profitability Analysis
Evaluates profit generated by individual product sub-categories to identify the most and least profitable products.

### 4. Regional Sales Analysis
Uses a geographical map to visualize sales distribution across different states and understand regional performance.
